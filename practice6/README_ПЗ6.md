# Практическая работа 6

Извлечение EXIF, свойств DOCX и PDF, самостоятельная конвертация DMS в десятичные градусы и карта геоточек.

В публичном репозитории находятся только код, зависимости и незаполненные примеры настроек. Исходные фотографии, документы, отчёт, координаты и результаты остаются локально.

## Установка

Требуется Python 3.10 или новее. Из папки `practice6`:

```powershell
python -m pip install -r requirements_pz6.txt
```

## Подготовка нового набора

Если заполненные рабочие файлы уже существуют, используйте их, не заменяя примерами. Для нового набора:

```powershell
Copy-Item test_data/journal.example.csv test_data/journal.csv
Copy-Item visual_location.example.json visual_location.json
```

1. Добавьте в `test_data/` 4–6 собственных фотографий и 2–3 собственных документа DOCX/PDF. Поддерживаются JPEG, PNG, TIFF и WebP. HEIC и RAW требуют отдельной подготовки.
2. Заполните журнал: имена файлов, ожидаемый GPS (`yes`/`no`), происхождение (`own`, `synthetic`, `educational`), дата включения в набор и настройки съёмки. Ожидания желательно записать до извлечения. Если настройки старых снимков неизвестны, укажите это явно.
3. Выберите снимок без GPS. В `visual_location.json` внесите наблюдения, выводы, альтернативу, предполагаемое место, координаты и ссылку на карту. Место определяется вручную по признакам кадра: программа не распознаёт памятники. `accuracy_m` задаёт условную зону неопределённости, а не измеренную точность.

## Запуск

```powershell
python pz6_metadata.py
```

Пути по умолчанию считаются от папки скрипта. Параметры другого набора:

```powershell
python pz6_metadata.py --data test_data --out out_pz6 --visual visual_location.json
```

Скрипт читает исходные файлы без перезаписи. EXIF обрабатывается Pillow и exifread, DOCX — python-docx, PDF — pypdf. Для извлечения метаданных интернет и токены не нужны.

## Результаты

В локальной папке `out_pz6/`:

- `images_exif.csv` — EXIF, GPS и сравнение парсеров;
- `documents_metadata.csv` — свойства документов;
- `journal_check.csv` — проверка журнала;
- `raw/*.json` — подробные EXIF, DOCX, /Info и XMP;
- `points.csv` — координаты с источником;
- `map.html` — карта: синие маркеры GPS и оранжевая визуальная оценка;
- `summary.json`, `pz6.log` — сводка и диагностика;
- `tables_for_report.md` — таблицы для заполнения отчёта.

Совпадающие маркеры объединяются в раскрывающуюся группу. При просмотре HTML-карты браузер загружает библиотеки и подложку из интернета. Для отчёта можно подготовить автономную координатную схему.

Статус `ready_for_manual_review` подтверждает автоматические проверки, но не правильность визуальной гипотезы. Отсутствующие свойства не заменяются выдуманными значениями. Полная история правок не восстанавливается из одного поля revision.

Повторный запуск перезаписывает результаты. Устаревшие JSON перемещаются в `out_pz6/_previous/`.

## Публикация и сдача

`.gitignore` исключает заполненный журнал, настройки с координатами, исходные материалы, результаты и отчёты. В публичном коммите остаются только незаполненные примеры. Заполненный отчёт в PDF и результаты анализа передаются преподавателю отдельно.
